# proto-transcription — Context

## Adding a New Transcriber

1. Create `src/proto_transcription/transcription/mymodel.py`, inherit `BaseTranscriber`
2. Implement `name` property, `load_model()`, `transcribe(audio_file: Path) -> tuple[str, list[dict]]`
3. Normalize segments to `{"start": float, "end": float, "text": str}`; call `self.format_segments()`
4. Wrap all library exceptions: `raise TranscriptionError(f"...{e}") from e`
5. Add model-not-loaded guard (see existing impls)
6. Register in `scripts.py` `transcriber_classes` dict
7. Create `tests/transcription/test_mymodel.py` — mock the library, not the transcriber

## Output Format

Each output file: `results/{audio_stem}_{model}_{model_size}.txt`
Header: Audio File, Model, Model Size, ISO timestamp — then `[HH:MM:SS] text` segments
